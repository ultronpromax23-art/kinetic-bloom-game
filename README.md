# Remix of Apex Fire

Core Gameplay

First-person shooter with smooth mouse aiming and WASD movement.

Left click to shoot.

Right click for aim/zoom where appropriate.

Space to jump.

Shift to sprint.

R to reload.

Add crouching with Ctrl.

Include hit detection, damage, health, armor, ammo, reloads, and respawning.

Add headshots with increased damage.

Create satisfying shooting effects: muzzle flash, recoil, hit markers, bullet tracers, impact effects, and sound effects.

Add weapon switching using number keys.

Include several original weapons:

Assault rifle

SMG

Shotgun

Sniper rifle

Pistol
